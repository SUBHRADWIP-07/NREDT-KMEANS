PROJECT NAME: NREDT-KMeans (Noise Reduction Enhanced Dynamic Threshold K-Means)

PROJECT OVERVIEW
                           NREDT-KMeans is an advanced clustering project designed to improve traditional K-Means performance by integrating noise reduction and dynamic threshold mechanisms. This project includes implementation, experimental notebooks, and visualization outputs.

KEY FEATURES: Noise-aware clustering, Improved cluster stability, Adaptive thresholding, Better performance than standard K-Means in noisy environments, Interactive visualization support

FILES DESCRIPTION
1.	DATASET (Folder)
	           Contains all datasets used in the project. These datasets are used for clustering experiments and evaluation.
2.	Customer_Segmentation_3D_Proper.html
	         This is an interactive real-time 3D visualization file of clustering results.
	      IMPORTANT: This file must be opened in a web browser (e.g., Chrome, Edge).
	                                        Do NOT try to open it in MS Word (.docx) or other document editors. It provides rotation, zoom, and interactive exploration of clusters.
3.	Copy of NREDT NEW IMPLIMENT.ipynb
	Main Jupyter Notebook containing the implementation of NREDT-Kmeans, can be executed using Google Colab or Jupyter Notebook.
